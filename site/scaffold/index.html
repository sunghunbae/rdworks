    breakup(parents, maxChildren=None, verbose=False) ¶

    Breaks up parents recursively and return a list of scaffolds.

    Examples:

    >>> [(rdmol, 'O=C(CCCc1ccccc1)N1CCn2cnnc2C1', 3, ((6, 7, 8, 9, 10, 5), (12, 13, 14, 18, 19, 11), (15, 14, 18, 17, 16)), ()), ..]

    Parameters:

    • parents (Any) –

      Chem.Mol object at first but changes during recursive calls

    • maxChildren (int, default: None ) –

      max number of children maxChildren = None --> scaffold network methods maxChildren = 1 --> scaffold tree methods

    • verbose (bool, default: False ) –

      print out children info

    Returns:

    • list –

      [(rdmol, smiles, nr, rings_indices, other_info), ... ]

    connect_core_and_chains(combi_smiles) ¶

    Connects scaffold core and chains(R-groups).

    combi_smiles has [expr:n] format where expr is an expression of atom mapping and n is the atom map number. It is modified from the Patrick Walters' work, Re: [Rdkit-discuss] reassembling a molecule from R-groups. Examples: >>> combi_smiles = "CN(C)CC(Br)c1cc([:2])c([:1])cn1.[H]C([H])([H])[*:1].[H][*:2]" >>> m = connect_core_and_chains(combi_smiles)

    Parameters:

    • combi_smiles (str) –

      concatenated SMILES containing core followed by chains.

    Returns:

    • Mol | None –

      Union[Mol, None]: connected rdworks.Mol object.

    expand_rgroup(core, r, prefix='RGX', start=1, **kwargs) ¶

    Expands or enumerates the core with R groups.

    core SMILES has [#0:n] where n is the attachment index. All attachments are enumerated.

    Examples:

    >>> core = "[#0:1]C1C([#0:4])C([#0:3])CN2[C@@H]([C@H](C3=CC=C(C#CC4=CC=CC=C4)C=C3)[C@]2([H])CN1C(NC5=CC=C(C=C5)OC)=O)[#0:2]"
>>> V = "[*]C#N.[*]C(O)=O.[*]CO.[*]C(NC)=O.[*]CNC(C)=O.[*]CC=C.[*][H]".split(".")
>>> W = "[*][H].[*]COC".split(".")
>>> X = "[*][H].[*]CC(F)(F)F.[*]OCCOC".split(".")
>>> Y = "[*][H].[*]O.[*]OC".split(".")
>>> output = expand_rgroup(core=core, r={1:V, 2:W, 3:X, 4:Y})

    Parameters:

    • core (str) –

      SMILES for the core.

    • r (Dict[int, List[str]]) –

      dictionary of {atom mapping number: list of SMILES for R groups}.

    • prefix (str, default: 'RGX' ) –

      name prefix of generated molecules. Defaults to 'RGX'.

    • start (int, default: 1 ) –

      start number for serial numbers. Defaults to 1.

    Returns:

      a library of generated molecules.
